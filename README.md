# Automation Engineer Playground

Automation Engineer Playground (AEP) is a hands-on learning system for practicing real-world Automation Engineering concepts through building, testing, debugging, and challenges.

The project is designed to go beyond basic automation tutorials by teaching why automation engineering concepts exist, what business problems they solve, and how reliable systems behave when things fail.

## What AEP Includes

- 10 progressive Automation Engineering labs
- Real-world business scenarios
- Guided builds
- Successful test scenarios
- Intentional failure scenarios
- Debugging exercises
- Independent challenges
- API and webhook engineering
- Reliability engineering
- AI automation engineering
- Capstone project
- AEP Learning Agent

## Core Technologies

The finished learner experience uses three tools:

- **AEP Website** — lessons, test requests, expected vs actual, hints, approvals
- **n8n** — where the learner builds the automation
- **Supabase** — persistence, for the labs that genuinely teach it

Built with:

- JavaScript
- REST APIs
- Webhooks
- Git / GitHub

While the website is being built, **Postman or curl** can send webhook test
requests, and **ngrok** is only needed if a local setup requires a public URL.
Both are temporary testing conveniences, not things AEP sets out to teach.

## Learning Approach

Each lab follows this structure:

1. Simple explanation
2. Business problem
3. Architecture / flow
4. Guided build
5. Successful test
6. Failure scenario
7. Debugging
8. Challenge
9. What You Learned
